## 2. 设计合理性评估

阶段二 Astra 报告：[PHASE-2-DESIGN-REVIEW.md](PHASE-2-DESIGN-REVIEW.md)。发现的重点冲突是手机工作台与手机范围限制不一致、实例即时开关与对象设置显式保存规则混淆，以及聊天记忆字段/迁移契约欠缺。按已有用户决定完成规格消歧；对尚无确认的运行语义保留“未决”。

## 3. 设计调整

| 调整 | 原因 | 结果 |
|---|---|---|
| 手机 AI 页只保留实例级总开关和状态 | 旧规格章节会误导为手机工作台入口 | v1.5 起统一；最终 NAS 六视口页面没有手机工作台入口 |
| 区分即时开关和显式保存 | 避免错误期待统一保存按钮或误报开关成功 | v1.6 明确保存/读取状态、未知结果重读和冲突提示 |
| 手机开关改用身份最小化读取与版本校验 | 按 instance ID 缓存可能跨账号或覆盖桌面新设置 | 增加窄接口、当前账号令牌和设置版本比较；冲突拒绝写入 |
| 统一“聊天记忆”产品名、固定字段和旧文本迁移约定 | 避免内部命名与用户确认要求不一致 | 规格引用可追溯用户确认文档 |
