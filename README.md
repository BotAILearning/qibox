## 使用

- 首次选择“下载安装微信”，或导入与设备匹配的官方 x86_64 / ARM64 .deb 包。页面提示当前设备格式，下载自动选择架构。安装按包结构、架构和实际能力判断，陌生版本号不会阻止安装或正常读取；通讯录与历史读取独立检测，失败不会显示为空数据。已核验的官方下载包大小与 SHA-256 见 config/wechat.json。安装一次可多开；这些声明不代表所有架构已经完成真机验收。
- 下载按 NAS 实际接收字节显示百分比、大小和近期速率；无法取得总大小时仅显示已下载大小与速率。安装按准备、校验、检查、解压、完成分阶段显示，校验和解压分别按实际处理字节计算，其他阶段显示处理中。
- 打开微信并完成官方登录，记录由微信保存在 NAS。栖盒不另存快照、不自动导入手机全部历史记录，也不将进程运行状态当作微信已登录或备份完成。
- 电脑左侧是桌面，右侧“精选应用”负责安装、添加到桌面、恢复和卸载。点击桌面应用图标打开，支持键盘 Enter；启动设置、重命名、停止和删除收在应用的更多操作菜单。
- 手机提供实例查看、登录、启动设置、重命名、停止和删除、可用实例的 AI 总开关，以及显式进入完整 AI 工作台的“AI 设置”入口。停留实例列表时仅读取轻量开关状态；进入后读取当前实例与微信账号的完整工作台状态，返回后停止完整轮询。手机登录界面可显示微信二维码；扫码和确认由微信决定。手机页面不提供电脑微信桌面的操作栏；原生桌面、文件授权、客户端及浏览器下载能力按实际状态提示，手机系统与浏览器兼容性仍需按实际环境验证。范围以[产品规格 1.14](docs/PRODUCT-SPEC-BASELINE-20260927.md)为准。
- 添加、重命名和恢复统一校验名称，使用中及保留数据的应用都不能重名；比较前去掉首尾空格，名称占用限于当前 NAS 用户。添加时默认提供未占用的名称。恢复旧数据遇到重名时，需修改名称后恢复，原实例 ID 和数据目录保持不变。

## AI 辅助

1. 先完成当前实例的微信登录，再从电脑界面的 AI 辅助入口配置自己的模型服务、接口、模型名称和 API Key。阅读数据发送说明并同意后，测试连接；不要把密钥或聊天记录发给支持人员。
2. 读取联系人后，选择要开启自动回复的对象及风格。未选择独立风格的对象跟随默认风格；独立风格单独保存。AI 总开关关闭时不执行自动回复。修改总开关不会清空模型、风格或记忆。
3. “智能判断是否回复”开启时，模型会决定是否回复；关闭时，仍受对象开关、限额、手动接管、可读取消息及安全校验约束，不保证任何输入都会发出回复。
4. 学习风格、记忆和分析报告先核对结果，再按页面确认应用。候选结果不等于已生效的设置。在执行记录中查看实际结果；发送状态未知时不要按消息反复重发。

请求按你启用的功能向所配置模型服务发送相关聊天内容和设置，可能产生服务商费用；价格、速度、留存政策和可用性由该服务商决定。模型密钥、个人信息、聊天记忆及相应历史在 NAS 上加密保存；执行记录可包含加密来信摘要和回复正文。分析报告及导出文件可能含聊天原文。关闭 AI 不会删除已保存内容，已下载的文件需自行管理。详见 [隐私政策](public/privacy.html)。

## 登录与故障恢复

- 显示“未登录”时打开该实例微信，按原生页面扫码，并在手机确认本次登录。二维码过期时使用原生页面重新获取。手机确认过期不能作为已登录证据；若微信拒绝从相册识别登录码，请使用摄像头扫一扫。
- 联系人暂时无法读取时，先确认登录的是预期微信账号，再使用页面的刷新或重试入口。状态未知不等于已经退出；不要为了刷新联系人删除实例或清空数据。
- 模型连接失败时，核对所选接口、服务地址、模型名称和服务商返回的错误。认证失败检查有效密钥与权限；限流、超时或服务不可用按提示处理。不要用另一模型的连接成功证明当前配置正常。
- 安装空间不足时先释放 NAS 空间，再重试。安装中断或失败不能当作已安装；重新打开页面检查实际状态。需要找回旧实例时，使用“保留的数据”恢复原目录；新建同名实例不会自动导入旧数据。

## 保留与删除

删除应用时默认保留数据。再次使用时从“保留的数据 → 恢复使用”选择原应用，再登录原微信。恢复复用原实例 ID、HOME、登录文件及聊天数据目录；不会凭微信账号自动匹配一个新建实例。存在保留数据时，在应用市场添加时会先提供恢复选择，仍可选择新建。

永久删除要求输入“确认删除”加应用完整名称，例如名称为“工作微信”，需输入“确认删除工作微信”。删除保留数据适用相同规则。

“卸载微信”移除共用微信程序和安装包，默认保留数据，重装后继续使用原目录。也可选择清除当前操作者名下全部微信数据，包含保留的数据，需输入“确认删除微信”。卸载先停止所有使用共用程序的微信，停止失败则不移除程序。入口限 NAS 管理员；清除数据始终限制在请求者自己的数据目录，不删除其他用户的数据。

## 启动设置

- 手动启动：需要时打开。关闭网页不停止微信。
- 持续备份：保存设置后立即检查启动，此后每 30 秒检查进程。登录后接收并保存记录。与电脑登录同一微信冲突，适合主要使用手机时开启。失败尝试间隔至少 60 秒，同一天连续 3 次失败后停止重试；主动停止会持续暂停，直到再次打开或保存设置。
- 闲时备份：按每日时段启动和退出（北京时间，支持跨夜），不再检测资格。前期需扫码；微信允许并勾选“自动登录该设备”后可在定时重启后自动登录。定时启动时栖盒尝试点击启动页“登录”，仍需扫码或手机确认时由用户完成；主动打开接管的会话不被计划强制关闭。

闲时模式可以直接选择、保存时段，不以资格检测锁住设置。微信自行决定账号在当前设备上是否允许原生自动登录；已登录、进程运行时间或旧手机确认都不能证明下次免确认。切换账号、搬到其他设备或实例后需重新核实。核对进度和历史方案边界见 docs/IDLE-POLICY.md。

## 应用目录

server/catalog.mjs 定义市场条目，桌面及保留数据保存 appId，旧数据默认归属 wechat。安装接口按 /api/apps/:appId/install/* 分派；保留旧安装接口兼容已打开的旧页面。当前只上架官方微信，不接受未适配的应用标识。后续接入新应用时仍需实现其安装库、运行器和设置策略；不是任意 Linux 安装包通用安装器。

## 构建与验证

需要 Node.js 22、Python 3 和 fnpack。运行依赖由 config/runtime-lock.json 和 config/runtime-lock-arm64.json 固定，缓存分别位于 .cache/runtime 和 .cache/runtime-arm64。微信不打进栖盒安装包。

```
npm ci
npm run prepare:runtime
node scripts/prepare-runtime.mjs --arch=arm64
npm run build:web
npm test
npm run check
npm run test:ui
npm run test:desktop
npm run build
```

上述为当前飞牛构建与验证入口。

工具路径可由 QIBOX_BUILD_PYTHON 和 QIBOX_PLAYWRIGHT 指定。npm run dev 提供本地页面预览，实际微信须安装到 NAS 使用。

飞牛统一包的输出路径为 `dist/qibox-<产品版本>-all.fpk`，包含 x86_64 和 ARM64 运行组件，依赖对应架构的飞牛 Node.js 22。启动只解压当前架构，新增字体由两种架构共用；打包支持双架构不代表 AI 原生适配已在 ARM64 实机验收。构建核对版本、入口、脚本权限、字体和全部组件哈希。平台差异、构建及安装步骤见 docs/MULTIPLATFORM.md；验收记录见 reports/RELEASE.md。
