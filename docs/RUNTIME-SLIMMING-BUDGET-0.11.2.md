# 0.11.2 依赖裁剪预算与功能保护

本表先于本轮运行组件裁剪建立，基线为 0.11.0-stable.003 完整通用 FPK **491,603,782 字节**；失败候选 0.11.1-candidate.002 为 **496,760,810 字节**。字节门槛为严格小于基线，构建按最终规范化 FPK 检查。预算不是最终包或设备验收。

| 组件 | 实际依据 | 计划变更 | 原始常规文件字节 | 压缩收益 |
| --- | --- | --- | ---: | --- |
| ARM Fcitx 拼音词库管理配置插件及独占 Qt WebEngine/QML/Quick 链 | 独立 ARM 清单、ELF 反向依赖与插件字符串/配置审计；27 个条目，链外 ELF 消费者 0。仅入口为 FcitxQtConfigUIPlugin，随包没有调用它的 fcitx5-config-qt；拼音引擎 pinyin.conf 指向独立 libpinyin | 按 ARM 自身文件签名删除 27 项；保留所有真实输入法引擎、词库、Qt Widgets 与 GTK 输入模块 | 137,591,743 | 重压缩后实测，不按原始字节直接推算 |
| 两架构共享 Qt WebEngine 资源与翻译 | 两架构均不保留 WebEngine 引擎及其配置插件；资源由 libqt5webengine-data 5.15.13+dfsg-1~deb12u1 提供，只供该引擎使用 | 删除 58 个无人使用的资源条目；保留该包 copyright 150,122 字节 | 24,356,613（共同层只计一次） | 重压缩后实测；源归档 7,282,992 字节不能直接当最终收益 |
| Python 3.11、LLVM 15、ICU、媒体库和字体 | 当前主机的组件/符号/功能证据不能证明最低版 1.2.0401 必装且兼容 | 最低版官方系统证据未取得前保留私有副本 | 0（本阶段不删） | 0 |

逐文件签名、来源包版本和功能保护签名由 `config/runtime-policy.json` 锁定；构建遇到来源改变、保留链接指向删除项或保留 ELF 依赖被删 SONAME 时拒绝输出。已有 x64 可选配置链裁剪属于基线，不重复计算为本轮收益。

第一项是 ARM 独立静态证据，不能冒充 ARM 动态/真机验证。前两项属于实际无用依赖裁剪，不属于“系统组件保证提供”的收益；最低系统复用的下载裁剪仍须另立官方来源、版本、ABI、符号与传递依赖证据。不得为达到体积门槛将未知系统组件记为可删。

功能保护覆盖 Python、虚拟显示、远控、D-Bus、窗口管理、拼音/中文表情、输入模块、字体、文件选择、音频和 FFmpeg/FFprobe。媒体自检新增编译与运行库版本匹配，以及本地 MP3 编解码、视频元信息和 JPEG 缩放。自检失败时原环境保留，不能进入就绪；未验证的系统复用仍走随包私有后备。

最终验收继续分别记录完整 FPK、固定官方微信、官方 Node 依赖、已有缓存升级下载、磁盘分配和临时峰值；没有测量的值保持未知。体积脚本明确不把 sizePass 当作功能、ARM 或最低系统验收通过。

## 已实施的归档结果

| 唯一压缩资源 | 裁剪前字节 | 裁剪后字节 | 减少字节 |

| 双架构共同层 | 121,072,104 | 113,901,836 | 7,170,268 |
| x64 专有层 | 160,776,176 | 160,776,176 | 0 |
| ARM 专有层 | 182,119,836 | 145,156,200 | 36,963,636 |

保留条目逐文件签名不变，无新增运行资源。x64 删除 58 项、常规文件 24,356,613 字节；ARM 删除 85 项、常规文件 161,948,356 字节。共同资源只计一次；上述压缩收益已经包含重新压缩，不能再叠加原始文件字节。

两架构都已独立检查 ELF 架构、依赖边、版本符号及完整资源哈希：x64 818 个 ELF、3,285 条依赖边，ARM 806 个 ELF、3,879 条依赖边，私有依赖缺项和版本符号缺项均为 0。两者要求 GLIBC 2.36、GLIBCXX 3.4.30。ARM 只有非真机证据。

固定离线修复容器 x64 为 274,964,480 字节，ARM 为 259,317,760 字节；这是随包资源的另一种离线导入封装，正常商店安装不重复下载它们，不是完整 FPK。完整 FPK 的最终大小以构建产物预算报告为准。

主测试系统上的隔离原生检查已分别验证系统复用及完整私有后备：微信空资料启动、中文表情剪贴板、输入法、私有音频服务和文件选择服务、MP3 编解码、视频元信息和 JPEG 帧。隔离测试未登录、未真实收发，不等于最终包回归。首次私有后备测试暴露长路径 D-Bus 套接字失败，现已按路径字节预算缩短会话目录，过长路径使用独占临时目录，停止后清理；修复后原生检查通过。原失败记录保留在忽略测试目录。

最低系统 1.2.0401 的正式镜像/组件证据仍缺失；未将 1.2.0800 的 468 个同哈希私有文件当作最低版保证，也未据此从 FPK 删除 Python、LLVM、ICU、媒体库或字体。系统保证组件的实际删除目标尚未达成，不能据上述体积收益宣布全部完成。
