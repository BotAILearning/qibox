逐文件签名、来源包版本和功能保护签名由 `config/runtime-policy.json` 锁定；构建遇到来源改变、保留链接指向删除项或保留 ELF 依赖被删 SONAME 时拒绝输出。已有 x64 可选配置链裁剪属于基线，不重复计算为本轮收益。

第一项是 ARM 独立静态证据，不能冒充 ARM 动态/真机验证。前两项属于实际无用依赖裁剪，不属于“系统组件保证提供”的收益；最低系统复用的下载裁剪仍须另立官方来源、版本、ABI、符号与传递依赖证据。不得为达到体积门槛将未知系统组件记为可删。

功能保护覆盖 Python、虚拟显示、远控、D-Bus、窗口管理、拼音/中文表情、输入模块、字体、文件选择、音频和 FFmpeg/FFprobe。媒体自检新增编译与运行库版本匹配，以及本地 MP3 编解码、视频元信息和 JPEG 缩放。自检失败时原环境保留，不能进入就绪；未验证的系统复用仍走随包私有后备。

最终验收继续分别记录完整 FPK、固定官方微信、官方 Node 依赖、已有缓存升级下载、磁盘分配和临时峰值；没有测量的值保持未知。体积脚本明确不把 sizePass 当作功能、ARM 或最低系统验收通过。

## 完整包集中回归与修复

`0.11.2-candidate.001` 完整 FPK 为 **452,738,175 字节**，比稳定基线减少 **38,865,607 字节**，比上一轮失败候选减少 **44,022,635 字节**。主测试系统上安装后的包内 511 个文件和恢复出的 869 个应用资源逐项一致，权限无差异。此包随后在正式入口逐屏复核发现手机暗色标题栏白底、文字对比不足，不能作为完成交付；原包、失败图片和日志保留。

根因为产品组合样式中移动工具栏和底部导航的选择器覆盖了通用主题背景。修复提高产品适配选择器的精确度，并将未选中导航文字接到语义颜色；新增 390/320 宽度的暗色背景、标题和导航一致性、导航文字至少 4.5:1 对比度检查。此修复不改业务值、API、模型调用或计时语义，集中构建的新包使用独立编号 `0.11.2-candidate.002`，最终大小仍须由构建检查实测。

已取得的原生证据分别保留层级：正式飞牛入口的后台准备及关闭页面后完成；官方客户端真实暂停/重启续传和固定哈希；受控 Bot 的中文表情往返、一次 AI 回复、人工文字以及文件/图片/MP3/视频四附件接收；五分钟人工接管首条新消息开始计时、追加消息不延长、到期后只回复一次；正常服务停止/启动后恢复已有会话。准备资源未打包进官方微信，现有账号和客户端保持原安装。

最终安装源码还用于隔离损坏/离线恢复：随包文件不可用时拒绝准备，损坏导入拒绝，固定离线容器恢复完整私有环境；单个 ffprobe 损坏后确认 13,645 项常规文件中的 13,644 项有效并予以保留，补齐后完整校验通过。另有明确标记的自检故障注入：有系统引用的候选自检拒绝后改为零系统引用的完整私有后备；新候选持续自检失败时旧环境原样保留并通过真实自检。这些故障注入不是最低版系统或真实 ABI 不兼容的替代证据。

## 0.11.3 后续启动修复与定向验收

历史升级范围已按用户澄清收敛到正式 0.9.70。其 FPK 哈希为 `b77ea646ddfadb77e6c21e68c6503b2c49e2c3629f817a73811eab6334d3ac12`；由该包真实代码和加密存储生成合成旧数据，再由当前 Instances 加载，验证密钥、账号、聊天记忆、手动风格、全局/对象接管数值、完成回执、运行计划、保留条目与用户文件。测试夹具仅含生成的假密钥和假模型配置，无用户凭据；加密资料扩展用于验证不丢弃未知字段，不宣称它是 0.9.70 当时的 UI 能力。该检查不等于真实历史聊天数据库逐条回放。

已定位启动阶段约 13,653 个文件、910,028,026 字节的全量核对。原已安装源码隔离测得首次 31,246ms、后续约 11,100ms。修复保持完整 SHA256、系统身份、链接/权限及变化拒绝：限制并发核对，按目标 inode/时间/权限签名复用解析结果，大文件使用两个受限工作线程计算哈希；核对失败前等候所有工作完成。工作线程异常回到完整原有哈希，不跳过校验。修改后同设备隔离首次约 13,138ms、后续约 2,750ms；这仍不是最终完整包入口时延。

同时将已验证且已运行桌面的缓存登录确认改为后台完成，目录不再等待该原生检查才可访问；未知登录状态仍保持未知，人工打开会接管，停止/退出会等候正在进行的恢复。同一原生恢复检查合并并发，不新增重试、模型请求或定时语义。已运行实例重复打开不再当作新进程启动重复全量检查；停止后的实际启动仍必须检查，异常仍拒绝。
