# 栖盒 0.11.0

本版继续使用用户自行配置的模型 API；不包含会员、支付、官方模型服务、中转及视频生成。稳定成熟后再规划 1.0.0。

## 资料与长期学习

“我的信息”使用 7 项常用信息和 5 项更多信息，单列摘要、展开编辑、群聊分享控制。旧字段迁移保留内容及逐条分享范围；隐藏旧入口不删除历史数据。手机可直接打开 AI 设置并编辑资料。

系统设置新增统一自动学习开关。无旧完整授权时默认关闭；关闭使尚未提交的学习结果失效，重新开启只处理新消息。已有手动学习保留。自动学习与自动回复开关独立，按消息增量和空闲批次处理，失败批次不自动重复调用。

本人信息、对象记忆和本人对该对象的表达风格分别管理。保存来源、归属、来源时间及更新时间；明确日期另存事件日期，未知不拿保存时间补造。自动资料默认不用于群聊，手动资料及风格优先，删除证据阻止旧消息恢复。相关事实有数量及长度预算，生成与发送前检查使用同份事实；聊天内容不能改变权限和系统设置。

## 设置与微信

消息合并使用最后一条消息后的等待及整轮最长等待；分段、续聊和人工接管分别计时。联系人和群聊可以继承全局或单独覆盖。群聊实时参与与回复快慢分别设置。支持资料和设置区域的明暗主题；主题能力由本产品实现，不代表共享组件运行库已完整支持全部规范。

兼容官方微信登录设置中的“自动”标签，继续使用账号绑定的自动登录、重连及会话恢复。消息、图片和文件能力以实际运行的官方客户端为准；手机确认仍可能由官方客户端要求。

## 闲时备份和安装资源

在线客户端可获取的消息实时同步与闲时计划分开。闲时计划按时间段检测系统负载、可用内存及整机网络流量；忙时退让，仅停止计划自己启动的客户端，人工接管后不再自动停止。可暂停和恢复，并对计划进程申请较低 CPU/I/O 优先级。

这些是准入阈值和尽力降低优先级，不是硬性资源上限；不能识别每个第三方任务的磁盘争用，不能承诺零影响。实时运行与手动会话不会因为闲时阈值被强制停止。

安装资源移除开发文档、测试、类型声明、调试映射及未使用的服务端浏览器包，保留运行数据、字体、许可证、双架构运行时和必要的离线资源。首次安装官方微信仍按原流程由用户获取官方软件。

开发者及联系邮箱统一为 bot@qiapp.online。历史归档不改写。

UI 依据 QIAPP 规范 2026-10-14 修订，实际随包组件 CSS 为 0.1.0。品牌层保留栖盒表达；规范尚未在运行库提供的能力由本次明确范围内的产品代码实现。

测试证据、真机账号及安装记录只保存在本地忽略目录；既有失败台账继续保留。小样本模型比较不代表所有聊天的效果或耗时保证。
