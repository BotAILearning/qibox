承接 0.11.8-candidate.027 的未发布稳定基线修复，当前源码候选为 0.11.8-candidate.095。本任务优先于后续整体验收；已授权源码实现、隔离测试、必要真实模型对照、授权测试对象真机验证、集中修复、统一打包、安装包回归、发布及相关 Git 同步。验收未完成不发布通过结论，不覆盖其他任务或历史包。

## 行为要求

- 区分当前作者、引用作者与事情主体；在同一次生成内结合双方原话、明确指代、已确认记忆来源和实际附带图片理解，不按发言人批量改事实主体。旧记忆没有新增元数据时继续兼容。
- 近期真人表达与最多三组、合计不超过 1200 字的真实上下文接话样例可用于本轮表达；AI 代发、未确认来源和歧义消息标识不作为真人风格。手动风格与锁定要求保持原优先级。
- 自动学习风格保持原五字段契约，改为简短具体的观察描述，避免沟通指导和每轮必做的情绪、总结、追问任务。
- 表情、笑声、称呼、反问和调侃从真人回复轮次学习为倾向；最近八轮确认的 AI 发送仅用于避免重复，不反向训练本人习惯。生成前选择当轮表达参考，沿已有失败记录或发送前持久化路径保存；同一已生成答复的确定未发送重试复用原计划，不新增跨对象写入等待。
- 采用独立 `styleRoundId`，不把对话结束/恢复版本当作每次回复的编号。同轮分段和重复确认只计一次；失败或发送未知不计确认，后续真实补核保持幂等。状态按账号、联系人隔离，内部统计不暴露为新的用户设置。
- 当前请求图片优先，已有三张上限内可补充已验证引用图及最近上下文图；本人 AI 或来源不明的图片不作为真人资料。图片保留原消息 ID、作者和时间，模糊缩略图不补造细节，模型不支持图片时沿既有降级路径清除对应图片来源索引。

不新增归属或风格发送拦截，不新增每条回复的模型审核请求，不机械改人称、增删表情或补装饰，不扩大既有产品重试次数。原安全、分享、取消、五分钟确定未发送重试和未知回执保护继续有效。

先实现、本地回归，再做冻结源码的真实模型对照、多轮人工复核、真机收发及集中修复；随后统一打包、安装包回归和发布。模型自评、模拟发送和统计数量不能代替真实业务结果。图片、身份归属和学习风险的原始失败保留。

只升级当前授权的主测试设备；辅助设备保持原版本，案例联系人不得作为测试收件人。设备身份、当前微信账号、登录状态及包/源码/进程来源在操作前核对。真机、对端接收、包回归、长期观察分层记录。

本地私人证据在忽略的 `local/ai-reply-optimization-20261022/`；项目案例和最终交付归档在用户指定项目的 `local/`。正式资料不包含私人聊天、凭据或真实联系人标识。会员、支付与已暂停平台不在本任务范围。

## 长聊天输入与接话修正（.079–.090）

用户已否定短而规则的归属问答作为核心验收。当前测试以长段多人、多事项、转述、否定更正及普通评论和收尾为主，真正求助另作对照。人工预期与事实来源单独保留，不传入模型，不用模型自评分数关闭缺陷。

模型输入保留双方完整相关原话、稳定作者、图片与引用绑定、时间及记忆来源。当前待回复长文在实际请求中只保留一份正文，重点索引引用原消息；不能为省 token 删除中段更正或用短摘要代替原话。生成口吻优先参考相关的真人配对回复，长段本人事实声明仍在上下文，AI 代发仅帮助衔接和避免重复，不作为本人风格样本。

普通回复在完整资料之后追加固定的本轮写作任务，仍保留原完整系统规则和用户手动风格。任务区分真正问事、普通分享和收尾，不把事实检查变成归属报告，不把已接纳的状态重述成提醒；对方自主安排不能自动变成给对方的待办。真实求助、显式详细或英文风格继续优先。普通中文不无故夹入外文碎片，真实专名、引文和明确外文要求保留。所有检查仍在原本同一次生成内完成，没有新增独立审核、产品重试、输出替换或归属发送拦截。

事实检查区分资料范围与人物状态：最后提供的物流记录不是本人最后一次查看；没有后续聊天不证明本人之后没有操作；没有到账通知不证明未到账；忘了最初找什么不证明物品没找到。来源不足时保留未知，不补第一人称理由、结果或精度。

真实模型对照保留了失败的精简系统提示和移动写作任务方案，未用更低 token 或单次成功宣布最优。请求实际用量、缓存读取、输出及失败分别记录；缓存命中不被当成输入资料缩减，服务价格和余额不可读时保留未知。
