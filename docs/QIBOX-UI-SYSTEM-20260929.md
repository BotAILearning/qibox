# 栖盒应用级界面组件与自测标准

栖盒沿用 qiapp 的基础颜色、输入框、按钮、弹窗和触控尺寸；`web/qibox-components.css` 负责栖盒工作台的页面组合。页面不能为装饰性介绍或数字步骤牺牲首屏操作空间。

## 组件

| 组件 | 用途 | 约束 |
| --- | --- | --- |
| `qbx-mobile-toolbar` | 工作台子页标题与返回 | 手机高度 56px；返回触控区 44px；标题与当前页同步 |
| `qbx-surface` | 信息和操作容器 | 内容决定高度；统一 16px 圆角、细边框和浅阴影 |
| `qbx-section-heading` | 卡片标题 | 标题说明当前任务；不使用 01/02/03 顺序提示 |
| `qbx-workspace` | 分析工作区 | 桌面左侧紧凑联系人入口、右侧分析设置；手机纵向排列 |
| `qbx-settings-links`、`qbx-settings-group`、`qbx-setting-row` | 设置导航及开关组 | 相邻组间距不超过 30px；说明文字随设置同行 |
| `qbx-switch` | 布尔开关 | 48×28px 轨道、20×20px 单圆点；关闭/开启均距边 4px |
| `qbx-bottom-nav` | 手机工作台导航 | 五个目的地等宽；选中状态文字对比度至少 4.5:1 |

## 自测层次

1. **结构**：分析页无数字步骤、无重复标题；联系人入口在独立紧凑卡片中，添加联系人的对话框可正常选人；设置页选项和通用行为连续呈现。
2. **几何**：320/390/1024/1440px 下无横向溢出；手机工具栏不超过 60px、联系人操作位于距页面顶部 170px 内、报告设置卡在 250px 内；空联系人卡高度小于 220px，入口宽度小于卡片的 72%。
3. **组件状态**：所有可见开关只有一个圆点；关闭和开启时圆点上下居中并在相应轨道端；导航选中项有可辨文字，按钮焦点可见；禁用的开始分析按钮不能发起请求。
4. **流程回归**：联系人选择、分析方向、时间范围、自定义要求、可选语音/图片、保存设置、子页返回、五个主导航、默认风格和模型页均检查。
5. **交付**：自动化检查和浏览器截图通过后生成 FPK；经 fnOS 应用中心安装；再以真实设备登录实例打开手机及桌面页面，检查版本、布局、交互和服务状态。构建产物与真机验收分别记录。

几何断言和截图由 `scripts/test-ui-proportions.mjs` 执行。该脚本使用一次性本地实例和模拟联系人，不会发送微信消息。真实设备检查仅做页面导航和联系人选择，不发送消息或创建报告。
