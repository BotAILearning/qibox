# 栖盒模块 UI 与页面顺序

适用于栖盒首页和 AI 工作台。沿用现有蓝紫色设计、控件和业务交互。

## 统一模块

- 模块卡片使用白色背景、1px 边框、12px 圆角，不增加独立阴影。
- 模块标题统一为 16px、650 字重；页面标题保留 22px。说明与状态使用次级文字层级。
- 桌面内容留白为 20px，窄屏为 16px，模块之间通常留 16px。带完整标题栏的模块将留白放在标题与内容内。
- 标题在左，模块的辅助操作在右。表单末尾先显示状态或说明，主要提交按钮放在右侧；空间不足时自然换行。
- 主要表单按钮在桌面至少 40px 高，860px 及以下至少 44px 高。返回栏沿用共用返回按钮；窄屏顶部返回控件为 44px。
- 折叠项使用相同的箭头、焦点和悬停样式。折叠只改变展示，保留字段值、勾选状态与原有保存方式。
- 危险操作使用明确文字与危险色，放在辅助操作位置，继续沿用现有确认与失败处理。
- 空的选择列表不保留大块占位高度；报告详情的复制、导出与删除操作在窄屏自然换行，保持可见。

`web/qiapp-adopt.mjs` 为既有模块补充 `qbx-module`。共用规则在 `web/qibox-modules.css`；新增自定义容器时需要同步适配选择器。不要将整页结构容器再次包成模块卡片。

## 排序原则

以使用频次、当前是否需要处理和操作的重要性共同决定顺序。常用操作与当前状态优先，高级配置、低频维护与历史随后；填写流程保持自然的依赖关系。调整实际页面结构，同时保持键盘顺序。

| 页面 | 顺序 |
| --- | --- |
| 首页 | 已添加的桌面实例 → AI 入口（窄屏）→ 精选应用 |
| 主导航 | 自动回复 → 主动聊天 → 执行记录 → 分析报告 → 系统设置 |
| 回复设置 | 触发开关与次数上限 → 实时状态 → 回复策略 → 多模态回复 |
| 系统设置 | AI 总开关 → 辅助等待及等待时长 → 身份说明 → 回复配置入口 |
| 回复配置入口 | 全局回复策略 → 我的信息 → 默认风格 → 模型设置 |
| 执行记录 | 来源与筛选 → 实时执行 → 最近异常 → 未回复记录 → 回复或主动聊天历史 |
| 分析报告 | 联系人 → 时间范围 → 选填方向、要求及媒体 → 开始分析 → 历史报告 |
| 我的信息 | 称呼、当前状态、近期安排、作息 → 需本人决定的事项 → 长期背景、偏好 → 更多信息与历史 |
| 全局策略 | 回复要求 → 边界 → 选填已知信息 → 保存 |
| 模型设置 | 已配置时先功能分配，再维护模型；添加或编辑时配置表单优先 |
| 默认风格 | 当前风格及确认保存 → 重新学习素材与配置 |
| 批量学习 | 对象选择 → 学习目标 → 时间范围 → 开始学习 |
| 主动聊天任务 | 联系人 → 沟通目标与选填要求 → 执行安排 → 核对与提交 |

联系人记忆保留姓名为首项，其后优先日常记忆、工作与日期；群聊优先概况、群内约定与共同事项。类别键和保存内容保持稳定。

## 验证

页面调整应同时检查实际显示、表单状态、键盘操作和窄屏布局。源码与临时浏览器预览的通过结果，不能替代 NAS 安装、真实微信或实体手机验收。
