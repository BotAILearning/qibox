# 验收状态与报告请求修复 0.10.48

联系人设置页原先将尚未保存的回复开关显示为“当前状态”，用户在草稿中关闭开关后可能误以为已经停止回复。当前状态改为读取已保存配置，编辑控件仍显示草稿；单聊与群聊同样处理。

聊天分析尚未取得记录范围时，页面原先显示“暂无可分析记录”。现在区分正在确认、尚未确认和实际为空的结果；部分报告完成时保留已确认范围并说明其余仍在读取。

实际报告生成出现模型响应超时。既有官方 GLM 5.3 请求适配只覆盖聊天和归属自检，报告格式请求仍使用模型默认推理量。报告格式请求现在使用该系列官方接口支持的 low 推理量并保持 thinking enabled；其他模型与自定义端点保持原请求参数。没有增加模型调用链、重试步骤或次数，也没有修改用户保存的超时、模型用途或密钥。实际效果须由安装后的同一对话生成复测确认，参数检查不能代替真实结果。

验证层分别记录源码、实际安装模块的隔离数据、主设备界面和真实模型结果。此前安装版的213项隔离检查没有向微信发送消息或访问真实模型，不能代替原生收发或完整功能/UI验收。闲时自动登录、长期观察、兼容设备和真实用户试用继续按各自条件记录。

构建期图像工具 sharp 的已知依赖问题随本版更新到 0.35.5。该工具仅用于构建图标和测试，不作为应用生产依赖分发；依据[维护者安全公告](https://github.com/advisories/GHSA-wq5f-xc86-pv6w)完成依赖扫描复核。
