日期：2026-10-28。用户授权本次真机验证、打包、发布及更新主测试设备。此版为候选版；历史稳定性台账及失败样本继续保留。

## 修复范围

- 风格来源增加明确下箭头及菜单语义，沿用多级选择器。
- 聊天记忆只显示当前分类，页签原地切换，保留未保存草稿与焦点；统一删除与关闭图标的居中和命中区域。
- 桌面群聊的 @我、@所有人、回复上限、应用全部同行；单聊智能判断、上限、应用全部同行。窄容器根据内容换行。
- 开启的真实提及需要生成回复，仍等待消息汇总；多人提及按发送者保留，模型在同一次请求中选择分条或同类合并，整轮最多 5 条。生成请求后到达的新消息进入下一轮。
- 模型未生成可执行回复时保留失败记录，避免同一失败批次随轮询反复调用；新提及或用户明确重试才恢复。不追加模型请求、独立审核或扩大重试预算，不用固定无关文字假装完成回复。
- 说明文案描述行为与后果；导航默认 144px、联系人栏默认 300px，支持拖动和方向键调整。
