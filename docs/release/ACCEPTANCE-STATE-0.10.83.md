# 0.10.83 首页启动修复与验证范围

首页曾在用户打开桌面前加载并解析远程桌面和完整 AI 工作台，同时等待 NAS 文件选择组件及多个样式请求。本版把桌面及 AI 资源延后到首次打开桌面时加载，文件选择组件不再阻塞首页初始化，公共样式按原顺序合并。桌面样式仍位于原来的级联位置，避免改变已有界面。

异步加载后重新核对当前打开操作和登录会话；加载期间返回首页或会话失效，不得重新连接旧实例。样式加载失败给出提示，重新打开可恢复。生成的脚本分块必须列在构建清单中，仍经过网关身份验证；未登记脚本和清单本身不对外提供。

普通与大数据使用相同的两秒预算和导航到可操作帧口径。历史失败样本、源码先失败再通过的回归、相同诊断条件下的性能对照以及最终包设备结果均保存在忽略的本地证据目录；额外 CPU 限速诊断不冒充日常环境或真机结果。源码优化和新的快速样本本身不足以宣布所有验收完成。

本版交付构建为 `0.10.83-stable.001`。缺陷闭环、最终包安装、设备回归及未完成的兼容性、恢复和真实时长观察分别记录在本地验收台账；不代表官方提交或全面放行。
