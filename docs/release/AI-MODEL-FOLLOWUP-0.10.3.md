# 0.10.3真实模型与安装跟进

真实MiniMax私聊中发现一次当前日期回答错误，下一条图片请求却续答了已经回答的日期问题。修正后把本轮待回复内容、全文对应ID及是否属于当前轮次直接交给模型，语音转换后的文字和不可读标记同步展示；旧来信和已发回复只作背景。

每次请求的系统指令明确实际日期、星期、时段及本人时区。发送前校验模型对“现在／今天”的明确日期和星期断言，错误时在原请求有界重试内反馈正确日期；连续错误保留待回复义务。引用、历史、未来约定及对方时区不按本人当前日期改写。

用户已允许的图片与音频能力和总媒体能力一致。明确的生成请求可返回生成任务，文字本身保持独立可用，不宣称生成已完成。生成失败仍按真实失败说明保留文字。

安装启动脚本使用本次刚创建进程的存活状态等待就绪，消除创建后尚未执行入口文件时的误报。隔离Linux测试中25秒冷启动成功、重复启动保留同一进程、退出进程约1秒报告失败。正式应用中心启动结果和真实微信收发在最终验收记录中补充。
