| 安全与隐私 | 静态缓存只服务认证后的公开文件白名单；API、凭据及账号数据保持 no-store。保留密钥加密、CSRF、身份/账号隔离及未知发送不重试。时间元数据仅进入已授权模型请求，不新增外部遥测。 |
| 可维护性与工程效率 | 静态资源、日志绑定和可见性刷新拆为小模块；新增真实子进程故障、HTTP/压缩、时间/核验边界及异步 UI 回归；保存明确失败原因与各层验收证据。 |
