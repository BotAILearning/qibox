## 行为

- 当前回复即时参考同一对象最近的本人手动表达，包括措辞、长短、标点、表情和接话方式；关闭自动风格更新时仍生效。已保存的明确要求优先，当前参考不改写保存的风格，不把旧样本里的答应当作对新邀约的授权。
- 监控已授权对象的新消息时增量整理有用知识，手动接续等待期间也可学习。普通回复等待与请求优先沿用回复中的提取，避免重复模型调用；其余监控材料合并20秒，独立学习请求间隔至少120秒。
- 按消息来源排除AI代发、来源不明及回执未核实的同文候选；对方和其他群成员不能作为本人口吻样本。事实须引用同一对象的有效消息证据；手动记忆保留，冲突作为候选。
- 独立监控学习每批最多80条新证据、25000字符，另附最多20条/5000字符前文；按到达顺序分批，进度只前移到实际提供的材料，不跳过剩余事实。首次启用建立基线，不自动上传旧历史。失败保留记忆并稍后重试；关停、切账号、取消后的迟到结果不应用。
