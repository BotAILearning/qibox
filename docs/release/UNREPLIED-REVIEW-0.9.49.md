# 未回复记录审查补全 · 0.9.49-debug.001

基于真机已安装的 `0.9.48-debug.001`（源码 `552229a`），按用户要求补齐未回复记录的“谁发了什么”。

## 行为

- 列表保留联系人或群聊、判断时间、原因与来源及原有操作，新增发送者、来信时间和原文。群聊一轮有多条相关来信时逐条展示。
- 群成员名称来自已验证身份对应的本地微信联系人记录。名称缺失或存在歧义时显示可区分的成员标识，不使用群名或消息内容猜测姓名，不输出原始微信 UID。
- 三类未回复路径保存当时的原始来信快照，正文与成员名称加密存储；语音、图片和视频可显示类型占位，不把后续模型加工内容当作原文。
- 旧记录按当前账号与原消息 ID 回读，只补全对应消息。同一联系人批量共享读取，普通状态轮询不扫描聊天历史。无法读取时明确提示并提供重试按钮。
- 快照最多保留 24 条、共 24000 字符，单条最多 12000 字符，并保留记录关联的消息；发生截断时显式提示。普通状态最多解密最近 50 条记录。
- 已恢复的旧消息可以从加密快照标记为需回复；审查、回读和显示本身不调用模型或发送消息。
