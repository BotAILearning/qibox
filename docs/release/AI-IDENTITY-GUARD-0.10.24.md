# 栖盒 0.10.24 身份回复保护验收（2026-10-02）

对方用“机器人”称呼并询问日常活动时，旧规则可能放过顺着称呼接机器身份玩笑的正文。本版在关闭身份承认设置时识别这种间接认领，不要求模型编造真人在场证明。

## 修复

- 识别“机器人🤖你……”等直接称呼，保护范围仍限于当前待回复来信。
- 拦截机器身份玩笑、常见空格和不可见字符绕过；保留正常机器人技术讨论、明确转述和示例。
- 身份底线进入生成和纠正提示；违规草稿重写一次，仍违规则记录 `identity-rule-block`，不发送，也不暂停后续群聊。
- 自动回复在原生发送前检查全部段落和语音正文，并逐段重新检查当前身份开关；主动聊天也在发送前复查完整正文。
- “承认 AI”开启时，仍只允许回应本轮实际身份问题；旧问题和主动聊天不获得披露许可。
