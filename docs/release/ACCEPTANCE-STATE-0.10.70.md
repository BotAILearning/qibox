# 0.10.70 手机范围、电脑入口与验收边界

已确认产品基线1.13要求手机端只提供实例管理、状态和每个实例的 AI 总开关。此前手机实例名称是进入完整工作台的按钮，会读取联系人；电脑工作台缩到手机布局后也继续保留完整页面。本版将名称恢复为文字，限制工作台进入与挂载为电脑布局，并在跨到手机布局时退出工作台、停止完整数据轮询。手机登录画面和轻量总开关保留。另修正电脑实例菜单的“AI 辅助”在桌面尚未连接时不打开工作台的时序问题：入口意图绑定当前实例及连接代际，连接就绪后打开，关闭或切换使旧意图失效。

生产页面隔离复现已保留原入口及完整AI读取；修正后覆盖320/390/760、手机横屏844以及请求桌面布局的980边界、电脑工作台正常进入、轻量总开关保存、退出后的轮询停止和合成登录画面。慢读取、失败停止请求、显式重试、保存结果未知后重读及离线恢复继续回归。以上为生产页面与可销毁合成账号，不是真实手机或微信登录证据。

本版只改变页面和产品版本标识，服务、原生模块、回复与模型请求链不变。逐文件核对后复用68的1242项服务测试和65的40场真实模型语义证据；不重复产生真实模型费用，不将历史微信往返冒充本版往返。69弹窗代际与处理反馈保持。

最终包与仅主设备安装按独立回执记录。当前真实微信仍需有效扫码；原生自动登录、72小时和7天、ARM、其他真实手机系统/浏览器、读屏、五名新用户、授权群和公开分发许可材料保持各自待验证边界。内部结果不代表官方审核通过。

电脑入口红绿回归另外核对旧数据同名实例、慢AI读取后关闭切换及刷新。旧分析历史测试曾把手机完整工作台当作预期，现按唯一规格修正手机段，保留电脑分析、历史、导出及账号切换原有检查；这属于纠正错误测试预期。
