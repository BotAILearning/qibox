# 0.10.73 验收状态

桌面实例停止请求未返回时，重新打开菜单仍可再次提交停止，生产隔离浏览器已复现两次请求与两次运行时调用。本版禁用等待中的停止入口，并在动作处理处拒绝进行中的重复停止；失败后回读状态并恢复操作。

回归分别记录桌面和手机模拟布局的启停等待、停止菜单重入以及启动或停止失败。输入为独立合成实例，不调用真实模型或微信发送。正式包、仅主设备安装和真实微信各自保留证据边界，辅助账号不升级。
