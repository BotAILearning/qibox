# 0.10.54 验证边界

本版修复受控回复质量样例中复现的缺陷。没有新增模型调用链、独立事实审核、自动纠错请求或扩大重试次数。

发送前的本地检查覆盖已复现的本人实时位置、无来源就业否定、确认后通知承诺，以及把“昨天”加写成“昨晚”或凭空声称昨天收到来信的情况。检查不会证明所有语义事实正确。被拦截的当前轮次明确记为未发送，不因拦截重放或再次调用模型。

官方 GLM 5.3 的 JSON 请求增加 `response_format: {type: 'json_object'}`；仅覆盖已知官方接口和该模型系列。语法正确仍不代表业务字段有效，原有业务校验及有限失败重试保持不变。

已有 40 条冻结合成样例使用实际保存的模型与默认风格完成评审，发现事实、承诺与格式缺陷。源码候选复测和定向回归仍单独记录，不能把模型生成成功、拦截后未发送或平均评分当成真实微信往返成功。不得宣称回复一定无法被识别为 AI。

源码自动化、安装包一致性、主设备安装和真实微信复测按不同层次核对。原生微信登录及联系人兼容、学习实际完成、最终版微信收发仍需当前账号已登录的证据；扫码条件不足时不伪造通过。

真实 ARM 设备、跨设备与浏览器覆盖、完整离线恢复、用户体验评审、原生免确认登录、72 小时及 7 天观察继续按真实资源和累计证据记录。内部验收不等同于飞牛官方审核通过。
