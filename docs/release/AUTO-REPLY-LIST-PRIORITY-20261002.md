# 自动回复列表排序与状态展示

联系人按已保存的自动回复开关排序，已开启者优先。群聊依次按实时回复、@我、@所有人、未开启排序；同级保留地址簿顺序。列表用回复状态和群聊已开启的触发方式替代风格摘要，保留暂停及上限状态。未保存草稿不改变列表已生效状态。

排序在虚拟列表截取之前执行，搜索仍覆盖全部地址簿，不修改联系人数据或对象配置。
