# 0.9.69 聊天记忆与回复验收记录

## 本次交付

- 自动回复和主动聊天按消息时间判断上下文。久远消息只作历史背景，不把旧病情、压力或旧安排当作当前状态；普通问候若模型仍接续旧临时状态，会重新生成，连续两次失败时改用新的简短开场。
- 自动回复接住本轮内容。对“不喜欢当导师”这类表达，允许试探具体负担，避免机械追问“为什么”；事实、能力和承诺仍以已确认的信息为准。未经明确授权的付款或借款请求在发送前统一改为拒绝。
- 长期记忆保存消息来源时间与观察时间；对“昨天”等相对日期按源消息时间计算。学习“风格 + 记忆”时两项共同待确认，用户点击一次“应用”后才一起保存；用户手动维护的记忆仍可增删改。
