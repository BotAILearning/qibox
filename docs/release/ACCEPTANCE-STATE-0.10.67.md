# 0.10.67 统一网关来源校验与验收进度

原 Unix 服务直接相信网关身份头；实际设备普通本地进程可连接并自称管理员。收紧 Socket ACL 后，这个设备上的当前普通用户仍能连接，原因尚未确定，不能仅凭权限位宣称修复。本版增加 Linux SO_PEERCRED 来源校验，仅允许平台 www-data、应用服务账号及系统 root，普通 HTTP 与桌面 WebSocket 共用检查。每个连接查一次；原生助手只读取内核 UID，限时失败即拒绝、不重试、不读 HTTP 内容。启动时先以所有者权限创建 Socket，再给 www-data 明确 ACL，失败不开放权限。

主设备自建隔离 HTTP 服务故意使用开放的模拟 Socket，实际普通用户和 nobody 三次保持连接请求均为403，实际 www-data 和应用账号三次均为200，每连接仅一次内核查询。没有读取其他用户数据。该证明独立于 ACL，但不能代替最终安装后飞牛网关和桌面验证。源码认证、CSRF、权限、导出、静态缓存和新增来源/权限测试16项通过。stable.001 未安装，最终交付候选为 stable.002。
