# 0.10.0 AI功能与回复可靠性

本次按2026-09-30用户确认开发，验收目标为飞牛x86_64真机及MiniMax；不包含视频、其他平台或公开发布。绿联实现、依赖及构建入口停止并移除，历史交付记录仅作追溯。

## 行为变化

- 我的信息按当前微信账号加密长期保存，包含15类选填字段、有效期、群聊分享范围、本人真实发言的待确认建议和历史恢复。全局回复策略支持对象继承与独立覆盖。
- 图片和音频文件输出需要逐对象勾选及模型媒体接口权限；音频明确说明为AI合成文件。生成失败保留文字回复。
- 5种内置风格为自然随和、简短直接、礼貌得体、温柔关心、轻松幽默。修改预设、默认或已学习风格新增自定义；自定义单独编辑、增加、删除及重命名，不删除对象或记忆。原样保存默认说明继续跟随默认风格。
- 自动回复、未回复、主动聊天记录分别支持确认后删除全部；确认包含尚未加载记录，确认期间的新记录保留。主动任务支持清空已结束。记录删除保留计数、去重和微信历史；保存失败恢复可见记录。
- 实时状态及回复策略默认折叠，自动回复及未回复记录默认展开，刷新保留折叠状态。只显示当前阶段，等待到期后的跳过按钮由后台可执行状态决定；等待重试可以直接点击。
- 回复记录可筛选联系人、群聊、全部；未回复列表加宽联系人、缩短并换行原因与来源，“标记/需回复”统一命名。回复次数上限保留1–99999或不限，按联系人/群聊分别批量应用并确认、反馈。
- 群聊请求模型时冻结本轮消息；新消息排入下一轮，多位成员的提及分别回复。信息不足保留义务等待补充，真实@我短等后回答或澄清；@所有人条件判断，实时正常模式允许参与合适话题、积极模式尽量参与。所有群聊触发共用该群上限。
- 保留一次私聊延迟续聊，以及明确要求停止后的5分钟等待。每次模型请求提供真实当前日期、时区、星期和时段，禁止编造上班、休息、天气、安排或未经确认的事实。

## 已定位的根因与处理

- 旧回复及未回复记录只保留固定窗口，页面补读也受首批限制：改为完整持久记录、分页加载及分批正文补读；删除只影响展示，不破坏防重发依据。
- 倒计时结束即隐藏跳过等待按钮，但后台仍可能排队：改为使用后台的实际可执行条件；不把倒计时作为按钮存在条件。
- 群聊新消息使已经开始的生成过时，最后一条消息可能覆盖较早的@：加密待处理队列、冻结发送人批次、稳定游标补读及发送前人工接管核验。
- 某会话失败触发全局等待，其他会话一起显示不可用：按对象隔离读取、模型和发送退避；取消操作不记为异常。
- 微信正常追加WAL时旧读取逻辑把稳定快照判为数据库变化：核对已发布前缀，允许同一日志的正常追加；重置、覆盖、检查点或身份变化仍拒绝。
- 模型结果缺少实际回复内容：增加结果结构验证与模型格式修正；仍失败则保留待回复义务，不直接吞掉来信。
- 发送结果未知和重启中的发送状态缺少正文恢复依据：提交前保存加密意图，通过真实微信记录补核；只点击一次，不自动重发未知结果。发送前核对当前账号、对象、空编辑器及自有媒体预览，避免操作其他弹窗或人工草稿。
