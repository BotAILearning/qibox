# 0.10.1升级恢复修复

0.10.0真机安装后的启动验收发现，历史运行环境备份中一个不同权限的Python缓存文件阻断了清理，运行环境准备失败。后续启动又使用了尚未准备的显示程序路径，产生重复失败。
