# AI 功能与回复可靠性验收（2026-09-30）

本轮按用户已确认的需求实施，范围为飞牛真机、MiniMax 验收和 GitHub 同步。功能基线是 0.10.0，真机发现的问题在 0.10.1–0.10.6 中继续修复。交互任务随后把本轮修复合入 0.10.7；保留最新合并版继续验收，不覆盖另一任务的改动。

## 需求与实现

| 范围 | 实现与核验重点 |
| --- | --- |
| 我的信息 | 当前微信账号加密长期保存，手动信息优先。15 类选填字段为姓名、称呼、个人简介、所在城市、时区、工作或学习、公司或学校、通常作息与工作时间、兴趣爱好、稳定偏好、生日与重要日期、近期安排、暂时状态、需要本人决定的事项、其他信息；支持有效期、群聊分享范围、历史恢复和真实本人发言的待确认建议。 |
| 回复策略 | 全局目标、事实和边界；对象可继承或覆盖，覆盖不丢失事实约束及回复次数上限。 |
| 多模态 | 逐对象勾选图片、音频并提示模型能力要求，不增加视频。MiniMax 实际图片和 MP3 文件收发验证；音频明确说明为 AI 合成，不冒充原生语音消息。 |
| 执行记录 | 自动回复、未回复、主动聊天分别确认后删除全部，包含未加载记录；确认后新增记录保留。主动任务可清空已结束。失败恢复可见记录，保留次数、去重及微信历史。旧记录固定保留窗口改为分页持久记录，正文分批补读。 |
| 折叠与状态 | 实时状态、回复策略默认折叠；自动回复、未回复默认展开；轮询保留折叠选择，只展示当前具体阶段。跳过等待和直接重试使用后台实际许可，倒计时结束不自行隐藏仍可执行的按钮。 |
| 筛选和上限 | 回复记录可切换联系人、群聊、全部。联系人和群聊上限分别确认、批量应用并反馈；前后端统一允许 1–99999 或不限，群聊所有触发共用该群计数。 |
| 文案与表格 | 统一“回复次数上限”“称呼”“标记”“需回复”；记忆表单保留姓名与称呼；移除无效“添加信息”和群聊参与方式冗余标题。未回复列表增加联系人宽度，原因和来源允许紧凑换行。 |
| 风格 | 五种预设为自然随和、简短直接、礼貌得体、温柔关心、轻松幽默。修改默认、预设、已学习内容新增独立自定义，不覆盖已有自定义；允许添加、删除及重命名，默认不可删除，默认和已学习不可重命名。 |
| 群聊等待 | 开始模型请求时冻结本轮发送人及消息，新来信进入下一轮；不同成员分别回复。信息不足保留待回复义务，@我短等后回答或澄清，@所有人按情况参与，实时普通模式允许合适话题插入，积极模式尽量参与。 |
| 私聊等待 | 保留一次延迟续聊；明确停止请求保留 5 分钟等待。人工发言使原生成失效，避免 AI 抢答或重复发送。 |
| 模型上下文 | 每次请求提供真实日期、时区、星期及时段；当前请求优先，旧失败任务不污染本轮。不臆测上班、休假、天气、日程、关系或未确认的事实，回复结构不完整时修正或保留待处理义务。 |
| 发送和异常 | 当前账号、目标会话、编辑器、前台、遮挡和附件均核对后发送一次，以真实微信记录确认；未知提交结果只补核，不盲目重发。单个对象的读取、模型、发送退避不拖累其他对象。正常 WAL 追加不误判数据变化。 |
| 系统优化 | 页面监听先建立，再恢复会话；恢复共享初始化、保留微信串行启动及关闭等待，单个用户失败隔离。明确暂停对象跳过无效读取，索引与快照复用减少等待；始终返回实际启动、登录及读取状态。 |
| 平台与弹窗 | 生产交互统一自定义弹窗，取消、Esc、关闭不执行操作。绿联实现、依赖及构建入口停止并清除，不生成绿联包；旧交付记录只用于追溯。 |
