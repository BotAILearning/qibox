# 【免费应用·内测招募】栖盒：在飞牛 NAS 上运行微信官方客户端

大家好，我是 Bot，做了一款飞牛应用——**栖盒**，想给有微信记录保存需求的朋友多一个免费选择。

**栖盒免费使用，运行的是腾讯官方 Linux 微信客户端。** 微信从腾讯官方来源下载安装，栖盒不修改微信程序。通过电脑浏览器就能打开 NAS 上的微信，支持多个独立实例，微信实际接收或迁移过来的记录保存在自己的 NAS 上。

可以按使用习惯选择三种方式：

- **手动启动**：需要时打开，用完自行退出微信。
- **持续备份**：登录后持续接收并保存记录。会与电脑登录同一微信冲突，适合主要使用手机的朋友。
- **闲时备份**：适合夜间等不使用电脑微信的时段，同样需避开电脑端登录。使用一段时间后，若手机微信提示允许本设备自动登录，完成授权且栖盒检测通过后开放。

手机历史记录需要通过微信自身的迁移功能导入；操作 NAS 上的微信请使用电脑浏览器。

当前为 **0.1.11 测试版**，开发者申请还在进行，暂未上架飞牛应用中心。先招募一批愿意反馈的朋友，测试包获取方式将在确认后更新到本帖。迁移速度、闲时自动登录及 ARM64 实机兼容性仍在验证，建议先用少量记录体验，保留重要记录的原始备份。

欢迎回复你的设备型号、飞牛版本和想体验的功能。遇到问题可附操作步骤和打码截图，我会在本帖跟进更新。

栖盒由个人独立开发；“官方客户端”指其中运行的微信，栖盒并非腾讯或飞牛官方出品。
