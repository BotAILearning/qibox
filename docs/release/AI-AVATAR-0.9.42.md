# AI辅助联系人头像：0.9.42-debug.001

基线为 GitHub `main` 的 `a96f32009c5098e8fa46106feef1502695e23fb6`（0.9.41-debug.001）。本批只改变 AI辅助联系人和群聊头像显示。

- 从当前微信实例的 `contact.db` 读取 `small_head_url` / `big_head_url`。仅接受已验证的微信头像域名；头像地址在栖盒服务内存中关联联系人，不写入 `ai-assistant.json`、报告或其他 AI 数据文件。
- 页面通过登录用户限定的同源接口即时获取图片，限制域名、图片类型、大小与请求时长，响应设置 `no-store`。没有头像地址或图片请求失败时显示默认头像。刷新联系人会重新读取微信数据库并重试头像。
- 不操作微信聊天、联系人资料页或发送消息。对微信数据库中完全没有头像地址的对象，当前只能等待微信自身更新后再次读取；本批未实现或宣称可强制微信客户端拉取新头像。
