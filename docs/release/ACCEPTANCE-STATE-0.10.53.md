# 学习适配与运行组件安全更新 0.10.53

52真实风格与记忆学习连续耗尽模型配置中的请求时限，原有效果保持不变。现有GLM5.3聊天与报告适配遗漏了学习用途；53为现有学习请求明确标记用途，在官方接口使用支持的低推理强度，保留思考功能、超时、输出预算和现有重试上限。自定义接口及其他模型请求保持原配置。

运行组件按Debian Bookworm官方修复版本逐项更新。InRelease使用现有Debian可信归档密钥验证，索引及下载包逐级核对SHA256，包内控制元数据和ELF架构单独核实。只替换已确认落后的组件，保留旧缓存及来源证据，不安装系统软件或执行包内维护脚本。

本版另纠正过时的隐私说明，按实际功能列明报告本地留存、记录正文加密、模型上下文与可选图片传输、个人信息分享范围、服务商计费及关闭功能后的留存边界。此说明不代表外部法律审核。

窄屏执行记录的打开聊天入口被共用按钮规则压到约40像素；本版恢复44像素触摸高度。浏览器用例同时按已批准的模块顺序、折叠入口和记忆类别顺序维护，原失败记录保留。

源码1174项及运行组件专项11项检查通过，35个包的签名来源、哈希、控制元数据与架构验证完成。当前处于构建与真机复测阶段。源码通过、通用包完整性、主设备安装、学习实际完成及运行依赖兼容必须分别记录；未取得相应证据前不关闭缺陷。ARM真机、长时间稳定性、额外环境、真实用户试用与官方审核仍独立待验证。本版不代表全面验收通过。
