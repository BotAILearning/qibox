# 0.9.58 自动回复恢复与“需回复”标记验收

2026-09-29。用户报告：某已开启自动回复的联系人来信后，等待六七分钟仍未收到自动回复，随后本人手动回复；此前“标记为需回复”按钮点击后也缺少反馈。

## 诊断与修复

- fnOS 真机只读诊断显示：当时微信聊天数据库写入和登录状态变化曾使聊天读取中断。旧版对连续联系人扫描失败采用最长 15 分钟的退避；这会使界面仍显示“自动回复已开启/空闲”，但实际上暂时不能处理来信。现在数据库变化或短暂登录中断后保留已有联系人资料，进入待恢复状态，并每 30 秒重试；其它故障仍保留原有退避。
- 对象页面在全局回复暂不可用时显示“暂不可用”及原因，不再显示“空闲”。
- “标记为需回复”显示处理中、成功和失败状态。成功后该行显示“已标记为需回复”，说明会在下一次自动回复前总结、不会立即发送；失败时在原行显示错误并允许重试。后端公开状态包含该标记，刷新后仍可识别。
- 用户已手动回复的消息由现有游标接管逻辑处理，不执行事后补发。本次没有向真实联系人发送测试消息，也没有改动其设置。
