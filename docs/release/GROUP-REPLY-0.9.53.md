## 问题与处理

- 2026-09-29 15:46—15:48，“距离少杰请客还远吗”出现已验证的 @我消息；倒计时出现后，15:51:35 开始发送，15:53:04 被记录为送达未知，没有确认的本人消息。现存记录不能还原当时助手进程被中断的精确阶段，也没有证据表明发到了其他联系人。其他聊天可能同时进行模型处理，但原生微信操作由同一桥接器串行执行，发送目标按账号和会话 ID 校验。
- 旧流程在发出提交指令时就标记“发送已开始”。如果此后用户操作触发手动接管、进程被终止，即使原生助手完成清草稿并报告从未按下发送键，外层仍把本轮记为“送达未知”，并消耗来信游标。这样安全避免了重复发送，却会漏回。
- 本版把原生助手是否按下发送键写入最终报告；只有完整报告明确证明未按发送键、草稿已清除或无须清理时，才记为未发送并保留重试资格。发送键可能已按下、报告缺失或草稿未安全清理时仍维持送达未知，不冒险重复发送。交叉会话接管的终止场景加入回归测试。
- 群聊实时回复的“积极参与”现在每 12 秒合并一轮有内容的新消息，提示模型默认自然参与讨论；“正常回复”维持 60 秒合并，要求偶尔参与。已验证 @我/@所有人优先处理，实时回复轮次之间至少间隔 30 秒，纯表情、刷屏、重复内容和已结束话题仍跳过。
