# 手机桌面实例删除修复：0.10.22

手机桌面原来仅提供登录或停止按钮，没有删除入口；共享实例操作处理逻辑还会拦截手机端。现在每个实例右侧提供“更多操作”，支持重命名与删除，复用既有确认窗口及服务端用户隔离。删除默认保留数据；选择同时删除数据后，要求输入“确认删除”加实例名称。

菜单和菜单项采用 44px 触摸高度。手机列表只在内容变化时更新；内容变化后恢复打开菜单和焦点。电脑端菜单恢复逻辑限定在电脑列表内，避免手机菜单导致空节点错误。手机只放行手机实例卡片的重命名、删除，其他桌面操作继续保持已有入口规则。
