# 0.10.82 变更与交付边界

微信重启时，数据读取进程可能在异步账号检查期间退出。旧进程完成清理后，请求仍被挂入旧队列，导致联系人刷新、自动回复和应用停止一直等待。本版在异步检查返回后再次检查退出和取消状态，让失效请求结束并释放队列。针对性回归先复现永久等待，再验证修复后可以重新扫描和读取。

本版同时交付登录画面提示、飞牛 HTTP 200 失效会话识别和会话失效后旧页面清理修复。失效会话不能被误判为成功下载，迟到的请求不能重新填充已清空的私有界面。手机范围回归等待实际布局切换完成，再检查工作区关闭和轮询停止。

交付构建为 `0.10.82-stable.002`，`.001` 是内部候选。设备、账号、模型服务状态、逐项测试结果、失败证据和备份记录仅保存在已忽略的本地验收目录。

本次稳定包面向既有 fnOS 测试环境交付。冷启动历史慢样本、72 小时与 7 天真实观察、ARM/iOS 硬件、独立普通用户、兼容矩阵、离线恢复和完整回滚仍按原台账保留。会话专项的隔离回归不替代最终原生门户退出复验；不表示全量验收或官方审核已完成。

模型服务的额度、限流及接口可用性独立于应用版本。稳定包不承诺外部模型始终可用；发送结果待核实时保持不重发，避免造成重复消息。在线备份可读也不能替代离线恢复验证。
