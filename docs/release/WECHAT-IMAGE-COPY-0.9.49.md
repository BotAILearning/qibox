# 0.9.49 微信图片复制修复

微信图片浏览器右键“复制”后，浏览器将图片写入当前设备剪贴板，不再打开文件保存位置弹窗。图片下载、另存为仍使用原有文件保存流程。

浏览器写入图片剪贴板需要 HTTPS 或其他安全上下文，以及允许页面使用剪贴板。若当前浏览器不支持，页面给出明确提示，不会误报复制成功。

验证：Edge 浏览器模拟微信原生复制请求后，读回剪贴板中的 PNG，确认图片尺寸正确、文件传输面板未打开且未触发下载。另运行文件导出服务测试。

2026-09-29 已通过 fnOS 应用中心将 `qibox-0.9.49-debug.001-all.fpk` 安装到 `192.168.3.7`，设备端包 SHA-256 为 `5dbc63e8f73352f7e3c31d850f0a6923446a3a7b837d534aaf9c62455cbe18cf`，版本、服务、原微信实例运行和登录均复核。真机测试在实际微信 X11 会话注入一张测试图片的原生剪贴板 URI，连接此设备的 Edge 浏览器读回 2×2 PNG，文件弹窗未出现，浏览器下载次数为零；测试图片已清理。该测试覆盖实际设备链路，未代替在微信图片浏览器中手动点击“复制”的验收。
