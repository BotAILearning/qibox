# 0.9.54 自动回复等待状态与跳过等待

## 改动

- 联系人和群聊的自动回复设置页持续显示当前对象的「等待」「请求 AI」或空闲状态。等待状态显示原因、剩余时间；手动接管后的等待和消息合并等待提供「跳过等待，交给 AI 回复」。
- 跳过操作由服务端核对当前对象仍有待处理来信，清除本轮等待并立即交给回复流程。对象停止回复、账号状态不满足条件或等待已失效时拒绝操作。
- 页面轮询仅刷新执行状态区域，保留未保存的设置草稿。
