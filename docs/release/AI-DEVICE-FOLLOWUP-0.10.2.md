# 0.10.2真机验收修复

在0.10.1的真实聊天验收中，定位到会话变化索引使用微信联系人编号、后台监控使用账号内回复档案编号，二者直接比较导致退回轮询。修复后按档案关联的联系人查询索引，新消息立即进入对应对象的处理队列；显式暂停的对象不再占用后台读取，其他暂停原因的既有恢复逻辑保留。

应用中心首次启动还需要等待共享环境准备和已保存的微信会话恢复。启动脚本延长有界等待，并在所属进程退出时立即报告失败，避免冷启动仍在进行却被报为启动失败。

新增真实编号结构的回归覆盖索引对应、末尾对象新消息优先、汇总等待持续读取、显式暂停不读取且计数保留、缺失会话轮转。最终设备收发、安装包和Git验证在验收完成后记录。
