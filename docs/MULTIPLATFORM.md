# 栖盒平台与架构

当前仅支持飞牛 fnOS。统一 FPK 包含 x86_64 与 ARM64 运行组件，启动时只准备当前设备架构；使用系统应用数据目录与飞牛网关身份。微信由用户从官方下载安装，程序不随栖盒安装包分发。

构建使用 `node scripts/build.mjs`，校验版本、入口、组件哈希和包内权限。x86_64 的真机验收与 ARM64 的构建校验分别记录，不能将双架构打包视作两种架构均已实机通过。

2026-09-30 按用户要求停止并移除绿联的运行入口、认证适配、SDK 依赖、专用原生辅助程序及 UPK 构建和测试脚本。历史验收记录作为溯源保留，不再作为当前平台能力声明。
