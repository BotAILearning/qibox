# 个人信息卡片 0.10.16 交付与验收

用户要求按真实聊天场景重设字段、输入长度、填写状态与主次层级，并取消有效期。入口仍为电脑端 AI 辅助 → 系统设置 → 我的信息。

## 字段与输入

全部选填，17 项沿用原有 15 个字段键，新增家乡及家庭与关系；已有资料无损保留。

| 默认位置 | 字段 | 输入方式与用途 |
|---|---|---|
| 常用 | 称呼 | 短输入，日常如何称呼本人 |
| 常用 | 所在城市 | 短输入，所在地与出行背景 |
| 常用 | 工作或学习 | 短输入，职业、岗位、学习方向 |
| 常用 | 作息与空闲时间 | 4 行，忙碌与方便联系的时间 |
| 常用 | 当前状态 | 3 行，近期影响聊天的状态 |
| 常用 | 近期安排 | 4 行，提醒写清具体日期 |
| 常用 | 兴趣爱好 | 3 行，日常话题 |
| 常用 | 生活与沟通偏好 | 3 行，喜好、忌口、联系习惯 |
| 常用，整行 | 需要本人决定的事项 | 4 行，约见、付款、报价等承诺边界 |
| 更多 | 姓名 | 短输入，用于正式介绍 |
| 更多 | 公司或学校 | 短输入，身份背景 |
| 更多 | 个人简介 | 4 行，已确认的经历 |
| 更多 | 生日与重要日期 | 3 行，可注明公历、农历及对应的人 |
| 更多 | 家乡 | 短输入，与当前所在地分开 |
| 更多 | 家庭与关系 | 3 行，本人愿意提供的关系事实 |
| 更多 | 所在时区 | 短输入，不填默认北京时间 |
| 更多，整行 | 其他信息 | 5 行，其他已确认的聊天事实 |

短字段已有多行或较长内容时使用多行框，避免单行输入丢失旧内容；保留原有每条 2000 字上限。“更多信息”、建议及历史可折叠，更多区同时显示已填写或待保存数量。

## 状态与资料兼容

- 未补充：灰色状态与补充入口；已填写：绿色状态、内容摘要及私聊/群聊分享范围。
- 编辑中：展开输入框，显示提示和字数；待保存：收起后呈现黄色状态，保存区同时显示修改数量。
- 保存成功读回服务端数据，显示成功反馈和填写数量，并收起已保存字段；保存失败保留所有草稿和原生效数据。导航与折叠保留同一账号草稿，切换账号或实例清除旧草稿。
- 保存、建议采纳和历史查看/恢复附带账号校验，拒绝旧账号操作。恢复历史和采用建议使用产品内确认；有相关草稿时提醒替换范围，取消或 Esc 保留草稿。
- 内容长期保存，由本人修改；旧有效期字段从读取、后续保存、历史恢复及模型上下文中移除，旧到期内容重新可用。分享权限、内容与身份保留；未修改的旧多值资料仍逐条保留分享范围，避免扩展到群聊。
- 模型区分填写时间与事件时间，结合当前日期理解过去安排，不能根据资料声称本人此刻正在做某事。其他等待、请求超时及确认令牌期限不受影响。
