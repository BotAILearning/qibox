# 图标更新与缓存

0.1.13 缩小透明留白、放大绿色盒子主体，统一更新网页与飞牛安装包中的各尺寸图标。背景保持透明，图标地址随内容哈希更新。

0.1.12 将浅薄荷色背景改为真实 Alpha 透明背景，保留绿色盒子主体。网页、飞牛桌面入口与 FPK 根图标统一从 web/icon.png 导出，并沿用下述内容哈希地址更新方式。源图与编辑提示词见 design/ICON.md。绿联网页构建同步资源，现有 0.1.9 UPK 未重新打包。

用户反馈安装 0.1.9 后，飞牛桌面、应用中心与栖盒网页仍显示旧图标。通过 SSH 只读核对，设备的 manifest 和 product.json 均为 0.1.9；ICON.PNG、ICON_256.PNG、UI 两种尺寸入口图标及 public/icon.png 的 SHA-256 均与交付包的新浅色图标一致。安装资源未漏替换，详见 reports/fnos-icon-installed.json。

0.1.9 桌面图标仍使用固定文件名 images/qibox_{0}.png；应用升级不一定让已经打开的页面重新请求同一地址。当前浏览器控制连接失败，尚未获取用户页面的实际请求与缓存命中记录，因此缓存原因属于待用户强制刷新验证的判断，不能声称已经直接观察到用户客户端的显示结果。

0.1.10 在构建时计算网页图标 SHA-256 的前 16 位，生成 images/qibox-<hash>_{0}.png 桌面入口及网页 ./icon.png?v=<hash> 地址。所有引用在构建时统一更新；入口 ID、应用 ID、网关和数据目录保持稳定。修改图标内容后会自动产生新地址，验证脚本会检查引用、两种尺寸图标及 FPK 根图标内容一致。

FPK 根目录的 ICON.PNG 和 ICON_256.PNG 为飞牛规定的文件名，应用中心自身如何缓存由系统控制。不要更改应用 ID、删除用户桌面配置或清空 NAS 数据来刷新图标。已打开的飞牛页面安装后需要重新加载入口；若仍使用缓存，可 Ctrl+F5 强制刷新。原生客户端可完全退出后重新打开。

本次仅交付飞牛 0.1.10 修订包。绿联保留 0.1.9 成品，后续构建也会使用带图片校验值的网页图标地址。
