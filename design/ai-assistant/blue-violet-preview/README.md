# 栖盒 AI 辅助 · 蓝紫设计预览

设计请求：参考用户提供的影视墙页面配色和风格，重新设计 AI 辅助。

## 预览

在本目录运行 `npm install`，再运行 `npm run dev -- --host 127.0.0.1 --port 4187 --strictPort`。

本地地址：http://127.0.0.1:4187/

## 本方案

- 深色左侧导航：自动回复、主动聊天、运行记录、模型设置。
- 主体浅灰背景，联系人列表和回复设置采用独立白色圆角卡片。
- 亮蓝主按钮与开关，浅蓝选中态，浅紫学习按钮。
- 个人联系人与群聊保留不同回复设置；窄屏分为列表与详情。

所有姓名、记录和模型连接均为示例。联系人设置仅存于本机浏览器的 qibox-blue-preview 键；API Key 不写入存储、不发送请求。运行任务仅用于展示界面状态。

正式产品源码和安装包未改动。本方案尚未由用户选定为新开发范围；后续应用前应保留现有全部真实能力，详见 design-qa.md。

图标：@phosphor-icons/react；其许可证随 npm 依赖保存。
